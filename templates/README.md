# Plantillas Excel publicables

Coloca aqui solamente libros Excel revisados y sanitizados que puedan publicarse.

Antes de agregar un archivo `.xlsm` o `.xlsx` a esta carpeta, confirma:

- no contiene CLABEs, cuentas bancarias, RFC, CURP, NSS, correos personales ni nombres reales;
- no contiene importes reales de nomina, proveedores o clientes;
- no contiene layouts bancarios generados con informacion real;
- los metadatos del documento no incluyen nombres personales innecesarios;
- las macros fueron revisadas manualmente;
- los datos de ejemplo son claramente ficticios.

Los libros Excel fuera de esta carpeta permanecen ignorados por Git.
